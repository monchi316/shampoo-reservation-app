# 企業向け LINEチャネル作成チェックリスト

このチェックリストは、企業担当者が「予約フォーム利用 + 通知受信」できる状態までを最短で整えるためのものです。

## 0) 先に結論

- 予約フォームでLINEログインを使うために、`LINEログインチャネル` が必要
- 予約完了/変更/キャンセル/リマインダー通知を送るために、`Messaging APIチャネル` が必要
- つまり運用上は **2チャネル構成** が前提です

---

## 1) 事前に準備するもの

- [ ] LINE公式アカウント（通知を送る対象）
- [ ] LINE Developers の利用権限（管理者）
- [ ] 運営から共有された予約URL（本番ドメイン）
- [ ] 連携担当者のメールアドレス（設定確認用）

---

## 2) LINE Developers で作成するもの

### 2-1. Provider 作成（未作成の場合）

- [ ] 企業名で Provider を作成

### 2-2. Messaging APIチャネル作成（通知用）

- [ ] チャネル種別: `Messaging API`
- [ ] チャネル名、説明、業種を設定
- [ ] 作成後に以下を控える
  - [ ] `Channel ID`
  - [ ] `Channel secret`
  - [ ] `Channel access token`（長期トークンを発行）

### 2-3. LINEログインチャネル作成（認証用）

- [ ] チャネル種別: `LINE Login`
- [ ] チャネル名、説明を設定
- [ ] Callback URL を設定（運営指定URL）
- [ ] 作成後に以下を控える
  - [ ] `LINE Login Channel ID`（必要時）

### 2-4. LIFFアプリ作成（予約画面起動用）

- [ ] LIFF App を作成
- [ ] Endpoint URL に予約URLを設定
- [ ] 作成後に `LIFF ID` を控える

---

## 3) このアプリ側（店舗設定）へ入力する項目

管理画面: `店舗設定 > LINE通知設定（企業別）`

- [ ] `LIFF ID`
- [ ] `Channel ID`（Messaging API）
- [ ] `Channel Secret`（Messaging API）
- [ ] `Channel Access Token`（Messaging API）
- [ ] `LINE Push 通知を有効化` を ON
- [ ] 保存後に `状態: 設定済み` を確認

---

## 4) 動作確認（必須）

- [ ] 予約URLを LINE で開いてログインできる
- [ ] テスト予約で通知が届く（予約完了）
- [ ] 予約変更通知が届く
- [ ] 予約キャンセル通知が届く
- [ ] （運営側）前日リマインダーの手動実行で通知確認

---

## 5) よくあるつまずき

- 通知が届かない
  - [ ] `Channel Access Token` の貼り間違いがないか
  - [ ] Push通知が ON になっているか
  - [ ] 友だち追加済みか（ブロックされていないか）
- ログインできない
  - [ ] LIFF Endpoint URL が本番URLか
  - [ ] LIFF ID の入力先テナントが正しいか
- 別企業の設定が混ざる
  - [ ] `tenantId` と `LIFF ID` の組み合わせが同一企業か

---

## 6) 運営へ共有する最終セット

- [ ] 企業名
- [ ] 対象 `tenant_id`
- [ ] `LIFF ID`
- [ ] `Channel ID`
- [ ] 設定完了日
- [ ] 初回テスト結果（予約/変更/キャンセル/リマインダー）
